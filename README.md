# Проект TeamFinder

Платформа для поиска команды и совместной работы над проектами.

## Описание проекта

TeamFinder — это веб-приложение, созданное для разработчиков, дизайнеров, менеджеров и других IT-специалистов.
Пользователи могут публиковать свои идеи проектов, находить единомышленников для их реализации, а также присоединяться к
уже существующим проектам.

## Ключевые возможности

- Регистрация и аутентификация пользователей.
- Создание и редактирование профиля пользователя.
- Публикация проектов с описанием, статусом и необходимыми навыками.
- Возможность присоединяться к проектам в качестве участника.
- Добавление проектов в "Избранное".
- Просмотр списка всех пользователей и проектов на платформе.
- Сортировка и фильтрация пользователей.

## Технологии

- **Backend:** Python 3.10, Django
- **Frontend:** HTML, CSS, JavaScript
- **База данных:** PostgreSQL
- **Контейнеризация:** Docker, Docker Compose
